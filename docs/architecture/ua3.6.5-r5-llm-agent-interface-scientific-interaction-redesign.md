## Facts and natural explanations

The existing accepted fact projection retains exact Revision, output locator,
subject, evidence digest, artifact identity and source pointer on local facts.
Providers receive bounded fact handles, values, original version/output labels,
registered descriptions, reviewed meanings and explicit comparison eligibility.
Unknown field meaning remains unclassified rather than acquiring invented units.

The existing evidence projection now describes native annotation fields directly:
`groups_omitted` is display coverage (`max(0, n_groups - 50)`),
`assigned_cells` and `unassigned_cells` describe computational assignment, and
`validation_state=not_assessed` does not establish biological validation.
The supplied group count is explicitly distinguished from proof of distinct
biological cell types. Original values and artifacts are unchanged.
Threshold-origin descriptions distinguish omitted native defaults from disabled
optional filters using accepted effective values: a non-null effective threshold
is enabled; null disables the optional filter. Argument omission alone establishes
neither a disabled filter nor a user instruction. Current owner defaults never
replace accepted historical values in these explanations.

New answers contain natural paragraphs with kind (finding, limitation or
conditional), fact citations and explicit comparison references. Deterministic
checks reject unknown/duplicate references, injected value/subject fields,
missing factual support and missing comparison operands. Existing owner-aware
comparison eligibility remains unchanged. Independent facts, partial answers and
explanations of insufficient comparison evidence do not require a comparison
pair. An asserted eligible comparison still requires its exact offered operands.
A separate, bounded provider call reviews factual consistency with accepted facts,
semantics, context and exact scope. Ordinary methodological descriptions and
conditional advice do not require exhaustive per-sentence citations; empirical
claims remain subject to review regardless of paragraph kind. The reviewer cannot
alter the statement, facts or binding. Any unsupported or
malformed review withholds the explanation; there is no evidence-only rewrite.
The complete consumed context is rechecked after generation/review, excluding
only active-status display changes. Guidance uses the same mechanism for its
complete bounded candidate set in one call, with exact capability/paragraph
verdict identities and explicitly unestablished readiness.

Semantic review is probabilistic language judgement, not mathematical proof or
independent scientific validation. Reusing the configured model can correlate
errors, and review adds latency/cost. Strict references alone do not prove prose;
scripted reviewer verdicts test control flow, not real-model reliability. Negative
real-model probes and positive controls are reported separately below.

## Option C — simplification before commit

The user approved four bounded corrections after the focused architecture review.
The changes are confined to the existing `scientific_dialogue` and
`scientific_guidance` owners, their consumer fixtures and documentation. Scientific
tools, accepted effective parameters, result authority, reports and durable
candidate-reference formats are unchanged. No additional reviewer model,
qualification framework, scientific validator or routing mechanism is introduced.
New evidence is isolated under `option-c/` in the R5 evidence directory; earlier
captures and acceptance records retain their original results.

1. **Threshold origin.** The misleading statement that omitted optional
   thresholds are disabled is removed. Explanations now read the accepted
   `effective_thresholds` value alongside exact execution-argument presence.
   Omitted minimum depth/TSS retain their enabled native defaults (1,000 and 4
   in the tested owner); omitted maximum depth and optional flank filtering are
   disabled when their accepted effective values are null. Explicit depth 1,700
   and flank evidence 20 remain explicit. These values exercise the existing
   owner's pure threshold function, without changing selection or recomputing
   accepted results. Historical values take precedence over current defaults.
2. **Comparison composition.** A comparison request no longer requires every
   answer to cite both targets or emit a comparison pair. Independently attributed
   facts, supported partial answers and explanations of missing comparison
   evidence are valid. Unknown references and pair IDs still fail deterministically;
   an asserted pair still requires both exact offered operands. Existing
   scientific eligibility controls remain. Comparative prose without an eligible
   pair is subject to factual review, including rejection of unsupported cell
   correspondence, causality and biological conclusions.
3. **Factual review.** The shared rubric checks empirical values, methods,
   source/subject/Revision attribution, claimed compatibility, causality,
   biological validation and execution/readiness. Supplied context and method
   definitions can support ordinary explanation without repeated sentence-level
   citations. Reasonable limitations and conditional scientific advice remain
   admissible; a conditional paragraph cannot shelter fabricated empirical claims.
   There are no tool-specific vocabulary rules or lexical validation passes.
4. **One Guidance review.** All one-to-four candidates first pass deterministic
   binding, then share one provider call over their common evidence and exact
   per-capability contract/readiness. Each verdict is keyed by
   `<capability>:<paragraph-index>` (or `answer:<index>` for an ordinary answer).
   Strict JSON parsing rejects missing, extra, duplicate or substituted IDs and
   unknown verdicts; dictionary order has no significance. Any failed paragraph
   withholds the entire candidate set. Existing candidate IDs, ordering,
   follow-up references, freshness checks and publication remain unchanged.

The transient reviewer wire is version 2, with an exact verdict object instead
of a positional verdict array. Historical presentations do not consume this wire;
their stored text and references remain readable without a compatibility engine.
Shared diagnostics distinguish `semantic_review_provider/provider_failure`,
`semantic_review_schema/invalid_review`, and
`semantic_review/unsupported_statement`; they disclose no provider exception
text. The user-facing failure preserves access to accepted scientific details.

Successful ordinary answers still use interpretation, generation and review:
three calls through the selected profile. Guidance now also uses three calls
regardless of whether it returns one, two, three or four candidates; previously
it used two plus the candidate count. There is no semantic retry or automatic
rewrite. Malformed generation is rejected before any review; the whole candidate
set is validated before spending its single review call. Review failure never
authorizes execution or changes an accepted scientific result.

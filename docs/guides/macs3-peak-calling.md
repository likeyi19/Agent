# Native scATAC peak calling

`call_scATAC_peaks` discovers experimental peaks with optional isolated MACS3 3.1.0. It is one Registry operation; import, QC, cell selection, feature counting, dimensionality reduction, neighbors, Leiden, UMAP and chromVAR remain independent operations.

Supply the accepted **native SnapATAC2 fragment-backed H5AD** defining the desired population. BAM input first uses `pp.make_fragment_file` with its actual barcode tag or regex, then `pp.import_fragments`. QC and requested filtering use their existing native operations. The caller pools the exact selected H5AD cells; it does not use cell-type labels or require clustering. A population retained by earlier study QC remains preselected data, not an unfiltered cell-calling benchmark.

State an effective genome size and its scientific basis/applicability. The owner never substitutes total FASTA length. The native peak-calling q-value defaults to 0.05. Exact contig exclusions are optional; none are inferred. The installed `snapatac2.ex.export_fragments` exports the selected paired fragments inside the existing isolated process owner. Their coordinates, cell IDs and native multiplicities are retained; MACS3 FRAG `--max-count 1` counts each exported record once. No second Tn5 shift occurs. Original BAM read-pair/PCR support is not reconstructed from native H5AD fragment storage and is reported as unavailable.

Results retain original narrowPeak, summit BED and XLS, an exact coordinate-ID BED in native order, ordered source cells, distributions, parameters, native software identities and source lineage. BED/narrowPeak coordinates are zero-based half-open; native XLS start/summit positions are one-based. Native probability fields are minus-log10 p/q; fold enrichment, pileup and display scores are distinct quantities. Pooled peak enrichment does not establish replicate-level differential accessibility or cell-type truth. Empty calls retain their native outputs without changing thresholds.

The accepted caller's **peaks** port binds its exact BED and checksum directly to `run_snapatac2(function_name='pp.make_peak_matrix')`. The matrix's dataset input remains the selected fragment-backed H5AD. The existing matrix owner retains native counting strategy and ordered cell/feature identities; peak calling does not count a second matrix. Preserve the fragment-backed source separately for native Gene Activity.

All three feature sources use this same native peak-matrix path:

- Compatible installed reference regions, including cCREs, bind through existing resource-component selection.
- Researcher-supplied BED regions retain their exact captured file and assembly declarations.
- Native caller-derived regions bind through the accepted caller output and retain its native order, source population and coordinate identity.

Existing regions do not require MACS3. Reference discovery fills unresolved inputs and does not replace an exact compiler-bound or accepted peak result. No old custom matrix builder or canonical-fragment import is restored. New peak publications use `macs3-scatac-peaks.v2`; saved v1 files, profiles and read-only evidence retain their historical identities. The old executable canonical-fragment/population preparation is retired.

The resulting H5AD can supply the [native scATAC methods](native-scatac-analysis.md), including SnapATAC2 feature selection, Spectral, KNN and Leiden, separately requested UMAP, and chromVAR. Native Scanpy/epiScanpy PCA remains available when selected for its scientific purpose; the retired Agent TF-IDF/L2 PCA path is not an active workflow. ChromVAR still requires compatible measurement, genome, coordinates and motif resources. Genomes with the same display assembly but different names or bytes must not be substituted. Preserve the matrix's recorded assembly declaration: changing `hg38` to `GRCh38` is not a way to select a differently labeled resource. When several installed genomes match the declared assembly, `genome_resource` selects an exact installed label or ID. The selected entry must still match that assembly. Operators may install an existing qualified reference's genome and explicit declaration in place, without copying its FASTA/FAI or changing another entry. This is not an assembly alias. Otherwise the task FASTA input remains available.

Ordinary Web resource selection uses the existing ScientificResourceLibrary. Fragment import consumes matching chromosome sizes; native TSSe and Gene Activity consume a compatible GTF/GFF. Native MACS3 peak calling does not require a cCRE vocabulary or a whole raw-reference bundle. In particular, hg19 BAM coordinates must use compatible hg19 inputs; an installed hg38 cCRE BED does not establish compatibility or authorize coordinate conversion.

## Optional runtime

Use an isolated Python 3.12.16 environment at `agent-data/resources/runtimes/macs3/env`; never install this backend into Agent's Python 3.11 environment. Install `MACS3==3.1.0` using the resolved `requirements.lock.txt` retained with the qualified runtime. Upstream distribution/license files remain installed. Run `tests/macs3/qualify_runtime.py --environment /absolute/path/to/macs3/env` once to record a new runtime identity and dependency lock. Existing identities are not overwritten. `AGENT_MACS3_EXECUTABLE` may point to another independently qualified environment with the same parent layout. Backend absence does not affect unrelated tools or Registry construction.

Native execution uses structured subprocess arguments, two CPU threads, cancellation and a two-hour execution ceiling. The retained native peak-output inspection has its existing two-million-peak bound; native fragment export uses the existing process memory/time boundary. No universal scalability claim is made. Native diagnostics remain private; download preparation removes private command paths from XLS headers and metadata while preserving statistical rows. Accepted reads/recovery do not repeat native science.

The [ICTA-4C-2 interim report](../../../agent-data/acceptance/iterative-cell-type-annotation/icta-4c/raw-fragments-benchmark/INTERIM_REPORT.md) records the cancelled campaign, integration evidence and incomplete acceptance. The [engineering review](../../../agent-data/acceptance/iterative-cell-type-annotation/icta-4c/raw-fragments-benchmark/engineering-review/REPORT.md) records subsequent source review and verification. Implementation availability alone does not establish complete researcher acceptance.

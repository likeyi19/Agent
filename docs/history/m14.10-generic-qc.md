### Science versus admission

`scatac_qc_profile`, `_barcode_qc_production` and `barcode_qc_verifier`
contain no species-dependent metric calculation. Canonical records count once,
regardless of support; QC depth and lengths use classified primary nuclear
contigs. Endpoints are start and end-1 with weight one, including coincident
endpoints for length-one records. Length bins remain <147, 147–293, >=294;
histogram bins remain 1–1000 and >=1001. Nucleosome signal is mono/free,
undefined when free is zero.

The frozen TSS definition is **all protein-coding transcript TSSs**, not one
TSS per gene or longest transcript. GTF [a,b] becomes [a-1,b); plus uses a-1,
minus uses b-1. Transcript IDs must be unique; each gene has consistent contig,
strand and coding eligibility. Invalid coordinates fail before exclusions.
Exclusions are noncoding, non-primary, then incomplete windows. Distinct
(contig, position, strand) sites survive; identical sites collapse, while
opposite strands remain distinct. Canonical BED4 is contig, p, p+1, strand,
ordered by FAI rank, numeric position, then strand. Lineage retains every
eligible transcript in rank/position/strand/gene/transcript order.

Genomic windows remain [-50,51), [-2000,-1900), [1901,2001) relative to p,
requiring 2000 <= p < length-2000. Every overlapping distinct TSS contributes.
Enrichment is exactly 200*center/(101*(left+right)); zero background is null.
No strand flip, clipping, aliasing, shift or population background is permitted.
The pinned BEDTools point-incidence profile and separate binary-search verifier
remain the QC scientific implementations.

Restrictions reside in `scatac_qc_reference`: the closed legacy schema admits
only human/hg38 or mouse/mm10, requires a legacy parent, limits classification
to 4096 contigs, and production annotation to the pinned narrow GENCODE GTF
dialect/source. Synthetic transcript TSV is expressly not a production parser.
The production qualification catalog itself has no species enum. QC and
selection artifact schemas, registry arguments and result schemas have none.
QC has no species-to-TSS or assembly-to-FASTA lookup: callers supply exact
manifest path/hash pairs. Catalog lookup is by exact qualified identity, with
the existing 16-entry bound; it never chooses a first matching species.
`_barcode_qc_binding` deeply reconstructs legacy resources and requires exact
parent identity/hash and ordered contigs. Scientific authority currently assumes
the QC parent is legacy. Those are resource admission/lineage boundaries.

`select_scATAC_cells` compares exact counts/rationals with explicit inclusive
thresholds. Minimum depth and TSS enrichment are mandatory. Optional criteria
are disabled when absent. There are no default or calibrated species profiles.
Undefined TSS fails; undefined nucleosome signal fails only if its maximum is
enabled. The selected sidecar fixes row order. No selection algorithm change
or arbitrary-species threshold calibration is needed.

`primary-nuclear-contigs.v1` already owns complete explicit FAI classification
and review provenance. Neutral external fragments bind it through preparation;
neutral BAM binds it through its input specification. QC must consume that
same authority, not infer a new primary set. The neutral matrix engine is
already shared with the legacy counter/verifier, but its existing profile and
public port explicitly require caller-declared cells. QC selection must retain
its own lineage rather than masquerading as an explicit-cell declaration.

### Frozen minimal boundary

Add a separate generic qualified normalized-TSS reference contract. Its resource
qualification binds species/taxonomy, assembly, the existing neutral reference,
the exact primary scope, normalized TSS content and immutable source/provenance
evidence. Normalized TSS admission does not claim to parse or independently
reconstruct arbitrary raw annotation formats. Production needs independent

self-declared provenance or matching hashes alone never qualify a resource.

Both reference contracts feed the existing QC owner and unchanged barcode-QC
artifact. Generic runtime validates qualification, resource integrity and exact
fragment/scope compatibility without re-proving raw annotation science.
Selection retains its artifact, profile, explicit criteria and owner. A selected
neutral matrix path must reuse the existing matrix engines and retain the QC
selection dependency, preserving the old explicit-cell contract unchanged.

## Implemented boundary

The architecture is now:

```text
existing qualified neutral reference + exact primary scope
  + independently qualified normalized transcript-TSS resource and lineage
  + raw source identity and immutable qualification evidence
    -> scatac-qc-reference.neutral.v1
    -> existing compute_scATAC_qc -> scatac-barcode-qc.v1
    -> existing select_scATAC_cells -> scatac-cell-selection.v1
    -> existing build_scATAC_cell_by_features
    -> scatac-cell-by-features.qc-selected.v1
```

Legacy QC references retain their original loader validation, builder,
reconstruction, profiles and serialization. The new loader dispatches by an
explicit closed contract identifier, never a species name or file name.
Registry remains **23**; no QC, selection or matrix tool was added. The shared
matrix tool admits one of two complete cell bindings: `selected_cells_manifest`
path/SHA (normal QC route) or the existing `explicit_cells_manifest` path/SHA
(caller override). Missing, partial or simultaneous bindings fail closed; no
cell set or missing workflow stage is inferred. The existing semantic compiler
binds the selection output to the newly declared optional port. Its algorithms
and v3/v4 wire versions are unchanged. V3's existing rule still requires unused
registered optional arguments to be explicitly null in model wire payloads.

### Qualification API and trust boundary

`neutral_qc_reference.qualify_reference` takes explicit keyword-only inputs:

- `reference_path`, `reference_sha256`: accepted neutral reference.
- `primary_scope_path`, `primary_scope_sha256`: exact shared scope.
- `annotation_path`, `annotation_source`, `annotation_release`: immutable raw
  annotation identity, source and version.
- `qualification_evidence_path`: immutable independent resource review.
- `tss_path`, `lineage_path`: already normalized canonical BED4 and eligible
  transcript lineage under the frozen legacy semantics.
- `output_path`: new no-clobber manifest destination.
- `synthetic=False`: explicit fixture-only mode when true, retaining the
  existing synthetic opt-in and size gates.

The API validates the neutral parent with its existing owner and validates the
existing primary scope, without deriving chromosome status. It independently
checks canonical site/lineage agreement, global transcript uniqueness, consistent
gene contig/strand, complete windows, bounds, site deduplication, strand identity,
and exact FAI/position/strand/gene/transcript order. Non-primary sites fail; they
are never silently dropped during admission. Publication fsyncs and creates a
new immutable manifest without modifying any input resource.

This API **does not parse arbitrary raw annotations or prove raw-annotation
completeness from a supplied subset**. Independent qualification evidence must
establish source authenticity, taxonomy/assembly compatibility, all eligible
protein-coding transcripts, exclusion policy and exact legacy TSS derivation.
Raw source bytes and that evidence are bound into the resulting resource. This
is the explicitly permitted qualified normalized-TSS boundary, not a replacement
GTF/GFF ingestion framework. The existing human/mouse GENCODE derivation remains
available and unchanged.

The API never issues its own production attestation. As for legacy resources,
the operator independently provisions `AGENT_QC_RESOURCE_CATALOG` only after
qualification review, binding the exact resource identity, parent identity,
annotation hash and release. Catalog membership binds the entire new resource,
including its normalized payloads, evidence, scope and dependency closure.
The trusted local operator/catalog model is unchanged: neither a self-declared
manifest nor checksums alone establish biological qualification.

The new closed generic reference uses `scatac-qc-reference.neutral.v1` followed
by NUL as its identity domain, hashing canonical complete JSON except the
identity field itself. It deliberately includes exact resource locators as well
as bytes and provenance; relocation requires a newly qualified generic identity.
This does not change the legacy QC reference's portable identity convention.

Production QC rechecks catalog admission, complete file integrity, explicit
parent/species/assembly/order compatibility and the exact scope pointer held by
the producer authority. It does not parse raw annotation, reconstruct its TSSs,
or independently classify chromosomes. Synthetic resources recheck normalized
content under the existing bounded fixture-only gate. The generic manifest has
an 8 MiB bound, at most 100,000 classified contigs, and the unchanged one-million
TSS/five-million transcript lineage bounds. The legacy 1 MiB/4096-contig
contract remains unchanged.

### Shared science, lineage and lifecycle

`_barcode_qc_production`, `barcode_qc_verifier`, both selection transformations,
the QC/selection profiles and their artifact contracts are unchanged. Generic
admission provides the same validated contig/TSS interface to those owners.
Neutral external-fragment and neutral BAM scope pointers come from their
existing producer records; missing or different scope authority is rejected.
Matching chromosome names alone is insufficient. The full scope, classification
review, neutral reference, FASTA/FAI, raw annotation, normalization evidence,
TSS and lineage remain current integrity dependencies for authority reuse.

QC selection remains exact, explicit and uncalibrated. It declares
`cell_call_method=none`, `cell_call_state=not_assessed`; no default thresholds,
statistical calling or singlet claim is introduced.

Selected feature matrices retain a `selection` scientific dependency in the
existing schema-2 authority DAG. Their frozen sibling profile is
`canonical-fragment-record-selected-feature-overlap-counts.v1`; it changes the
row-contract description, not overlap/count/CSR science. The legacy explicit
cell matrix contract/profile remain byte-stable. Both neutral routes use the
same counter, independent interval-tree verifier, publication/receipt envelope,
recovery policy and logical sparse identity. Exact fragments must match the
selection's QC lineage; target features remain within the same primary scope.
No selected-cell-to-explicit-cell conversion artifact is created.

Figureless reporting distinguishes QC-selected candidates from caller-declared
cells. Old explicit-cell report text is unchanged. The model-adaptation input
adapter recognizes the new fragment-derived contract for backend qualification;
it adds no model operation or EpiZoo change, and no model acceptance is claimed.

## Scientific scope

Every observed original `(namespace, barcode_identifier)` has exactly one row.
Namespaces remain separate; ASCII case, punctuation and suffixes are preserved.
Rows sort first by namespace ASCII bytes, then barcode ASCII bytes. The ordered
identity digest is SHA-256 of `agent.ordered-observed-barcodes.v1\0` followed by
each `namespace<TAB>barcode<LF>`. No rendered combined cell ID participates.
The set is nonempty for accepted nonempty upstream artifacts. A barcode observed
only on retained non-QC contigs remains present with zero QC counts and undefined
ratios. A whole artifact containing no QC-contig records is also supported.

All universal quantities count canonical fragment records, never their support
field. They make no molecule-count or original sequencing-depth claim. Producer
support is not included as an extra QC diagnostic. No mitochondrial fraction,
other-contig fraction or threshold is introduced.

| Metric | Exact definition |
| --- | --- |
| `n_fragment_records` | All canonical records for the tuple, on all retained contigs |
| `n_qc_fragment_records` | Records on exactly `primary_nuclear_qc` classified contigs |
| `tss_center_count` | Endpoint–TSS incidences at inclusive offsets -50 through +50 |
| `tss_left_flank_count` | Incidences at -2000 through -1901 |
| `tss_right_flank_count` | Incidences at +1901 through +2000 |
| TSS enrichment | Reduced exact rational `200*C / (101*(L+R))` |
| `n_nucleosome_free` | QC records of length 1–146 |
| `n_mononucleosomal` | QC records of length 147–293 |
| `n_longer` | QC records of length >=294 |
| Nucleosome signal | Reduced exact rational mono/free |

Endpoints are `[start,start+1)` and `[end-1,end)`, weight one each. Length-one
records contribute twice at the same position. No second Tn5 shift occurs.
Distinct TSSs, including coincident opposite-strand TSSs, retain incidence
multiplicity. No strand filter, window union, deduplication or TSS sampling occurs.
TSS background zero yields `NA`, `NA`, `ZERO_TSS_BACKGROUND`; free count zero
yields `NA`, `NA`, `ZERO_NUCLEOSOME_FREE`. Defined zero is `0`, `1`, `DEFINED`.
No infinity, rounded authoritative value, borrowed population background or
implicit zero replacement is permitted. Future comparisons can use integer
cross multiplication. Python integer/Fraction arithmetic preserves exact values.

The length histogram is **whole artifact**, counting QC-contig records only.
There are exactly 1,001 rows: exact lengths 1–1000 and overflow >=1001. There is
no per-barcode or per-namespace histogram. Summaries contain exact eight count
totals, depth min/max/rational mean, defined/undefined counts and rational min/max
for both ratios, histogram record total and overflow. Undefined values do not
participate in ratio extrema. Quantiles and floating-point distributions are
not part of v1.

## Public API and artifact

```python
from agent.tools.data.scatac_barcode_qc import compute_scATAC_qc

result = compute_scATAC_qc(
    fragments_manifest_path="/absolute/fragments/manifest.json",
    fragments_manifest_sha256=fragments_sha256,
    qc_reference_manifest_path="/absolute/qc-reference/manifest.json",
    qc_reference_manifest_sha256=qc_reference_sha256,
    output_dir="/absolute/managed-output",
)
```

All five arguments are required; there are no scientific/backend/overwrite
options. Application owns its managed output destination. The bounded 14-field
result contains status, manifest path/hash, artifact/schema/contract, observed
barcode count, total/QC record counts, TSS defined/undefined counts, science
profile SHA, QC resource identity SHA and resource qualification mode. Registry
argument/result validation is IO-free. It checks types, closed fields and
internal count constraints; fresh scientific verification remains separate.

One destination `barcode-qc-<execution-token>/` contains:

* `manifest.json`: canonical JSON, artifact `agent.scatac-barcode-qc`, schema 1,
  contract `scatac-barcode-qc.v1`, policy `compute-scatac-qc-v1`.
* `barcodes.tsv.gz`: header and exact rows, ASCII/tab/LF, gzip level 6, mtime 0,
  empty gzip filename. Production emits deterministic compressed bytes in the
  same runtime. Verification checks complete compressed digests and exact decoded
  rows; gzip encoding itself is not a substitute for source-level verification.
* `lengths.tsv.gz`: no header; `bin<TAB>count<LF>`, ascending bins 1 through 1001.
* `receipt.json`: closed versioned publication/recovery receipt.

The frozen 16-column table is:

```text
namespace barcode_identifier n_fragment_records n_qc_fragment_records
tss_center_count tss_left_flank_count tss_right_flank_count
n_nucleosome_free n_mononucleosomal n_longer
tss_numerator tss_denominator tss_validity_reason
nucleosome_numerator nucleosome_denominator nucleosome_validity_reason
```

The display above wraps; the physical header is one tab-separated line. All
counts are canonical nonnegative decimal integers. Each manifest binds exact
input paths/hashes through `arguments`, fragment parent-reference identity, QC
resource identity, science profile hash and TSS method, producer authority and
its verification/history limits, resource qualification, backend identity,
ordered-barcode digest, row count, both relative sidecar paths/hashes/sizes,
exact summaries, and domain-separated manifest identity. The source manifest
hash transitively binds its fragments identity. No per-barcode JSON appears.
`BarcodeQCManifest` stores immutable canonical bytes and returns defensive
decoded copies. Artifacts are immutable publications, with no overwrite path.

## Fresh qualification and execution

Execution and fresh QC verification require the exact fragments manifest hash,
fresh generic v2 checks, and the applicable existing producer verifier. FASTQ
checks its qualified source/producer record without rerunning alignment; BAM
independently reconstructs its transformation; external adoption independently
checks conservation. Declared upstream history retains each producer's limits.
Unknown/fabricated profiles cannot become qualified through generic v2 alone.
Producer dispatch chooses verification authority only; all metric calculations
consume the common reader with no producer-dependent algorithms.

QC reference sources are independently reinspected. Parent reference identity,
parent manifest hash and ordered contig dictionary must match fragments exactly;
species alone is insufficient. The frozen M11.4a TSS sidecar remains authoritative
only after source reinspection.

`AGENT_QC_BEDTOOLS` must explicitly name the qualified executable. The unchanged
M11.4a adapter checks executable/version/linked-library hashes and runtime policy.
No PATH executable discovery or alternative backend is supported. BEDTools only
executes the frozen `intersect -sorted -g <FAI-dictionary> -a <endpoints>
-b <windows> -wa -wb` mechanics. Endpoints and windows are independently sorted
by FAI rank/start using disk-backed SQLite; fragment order alone is insufficient.
Agent generates endpoints/windows, associates barcode tuples, accumulates exact
integers and calculates ratios. The independent verifier never runs this
intersection; runtime qualification may still invoke version/linked-library probes.

## Production resource gate

M11.4a GTF provenance declarations alone do not qualify a production bundle.
An operator must independently audit/provision resources and configure an
absolute `AGENT_QC_RESOURCE_CATALOG` path. This trusted runtime attestation is
separate from AgentRequest and planner control. QC checks its exact bindings;
it does not independently prove an operator's scientific audit occurred.

The closed catalog schema is:

```json
{
  "artifact_type": "agent.qc-resource-qualification-catalog",
  "schema_version": 1,
  "resources": [{
    "resource_identity_sha256": "<exact QC resource identity>",
    "parent_reference_identity_sha256": "<exact parent identity>",
    "annotation_sha256": "<exact source annotation digest>",
    "annotation_release": "<exact declared release>",
    "qualification_basis": "<operator audit identifier>"
  }]
}
```

The runtime catalog is bounded to 64 KiB/16 unique entries, with strict SHA/token
fields and exactly one matching entry. Its complete byte digest and audit basis
are bound into QC publication and fresh verification. Catalog edits, including
byte-only changes, invalidate reuse; there is no arbitrary matching-output scan.

Synthetic-only M11.4a bundles instead require `AGENT_QC_ALLOW_SYNTHETIC=1`, <=1,000
TSSs, <=1,000,000 total reference bases and <=10,000 fragment records. This path
is explicitly recorded as synthetic-only, cannot qualify a declared GTF production
resource, and is for tests. A test catalog approving tiny generated GTF fixtures
tests the gate's mechanics, not biological production acceptance.

No canonical independently qualified hg38/mm10 QC bundle is provisioned here.
Real execution remains gated by that availability. There is no HOMER fallback,
GENCODE download, annotation inference or resource construction during QC.
Biological validation remains M11.8; the heart fragment candidate is not used as
cell-calling truth. No biological data search/run is part of this milestone.

## Independent verification and lifecycle

`barcode_qc_verifier.verify_barcode_qc` freshly binds all upstream authority and
reconstructs counts into its own disk-backed database. It loads the bounded sorted
TSS positions and uses binary searches over inverse integer intervals for each
separately reconstructed endpoint. Length logic and rational serialization are
independent of production. It compares every ordered row byte, exact universe,
ordered identity digest, summaries, histogram, and compressed sidecar hash/size.
It imports neither the production aggregate helper nor its BEDTools intersection.
File snapshots and resource rechecks detect changes across verification.

Self-consistent, rehashed forgeries of record/QC/TSS counts, ratios/reasons,
nucleosome bins, dropped/added/reordered/substituted identities, summary and
histogram fail this source-level verification. Hash validity alone is insufficient.

The existing durable hook binds run, plan fingerprint, step/tool and exact args
through execution identity, plus source manifest hashes, QC/method/runtime/resource
qualification and destination, under `compute-scatac-qc-v1`. Publication is private
until independent verification succeeds, followed by receipt, fsync and atomic
rename. No automatic same-step scientific retry or overwrite is configured.
Recovery addresses only the exact token destination, checks its receipt and
freshly verifies QC; production QC is not repeated. Changed source, resource,
policy, qualification or output fails closed. Publication-before-checkpoint and
checkpointed-success recovery use the existing persistence machinery.

Cooperative checkpoints use the existing executor cancellation intent/state
machine through a scoped callback. Checks cover QC streaming, row export/hashing,
before publication, lock wait and active BEDTools polling. Cancellation terminates
an active intersection and cleans private scratch. Existing upstream verifier
calls and individual SQLite sort operations may delay observation until they
return; cancellation is cooperative, not a hard interrupt deadline. Published
verified success is retained when cancellation arrives afterward.

## Resource bounds and deferred work

Manifest <=1 MiB; rows <=4 KiB; observed tuples <=10 million; fragments <=1 billion;
each compressed sidecar <=16 GiB. Fixed 1,001-bin histogram. The inherited QC
resource limits include <=1 million distinct TSSs and <=5 million transcript rows.
Each incidence count is bounded by two endpoints × records × distinct TSSs
(<=2×10^15), safely below signed SQLite integer capacity. Ratio arithmetic uses
arbitrary-precision Python integers. No full fragment file or cell-by-TSS matrix
is materialized in Python.

Production and independent barcode accumulation use disk-backed SQLite with an
8 MiB page cache per connection and file-based sort temporaries. Production also
stores endpoints/windows on disk. Its main database has a periodically checked
64 GiB guard; this is not a total filesystem quota. BEDTools output is checked
against 16 GiB while running and afterward (polling allows transient overshoot).
Disk exhaustion fails without publication; large input limits are bounds, not a
claim of full-scale throughput qualification. The independent position lists
need roughly 36 MiB for one million Python integers, plus list/dictionary overhead.
BEDTools active overlap memory varies with window density. Upstream generic v2
verification still retains its all-barcode set, and QC source reinspection has
its existing resource behavior. No constant-memory end-to-end claim is made.

Optional retained-contig diagnostics, cell selection (M11.4c), true statistical
cell calling, doublets, FRiP, peak/cCRE/blacklist overlap and matrix construction
are not implemented. Stronger hostile-filesystem race protection and full-scale
performance/biological acceptance remain outside this synthetic milestone.

## Final acceptance audit follow-up

The final audit reproduced and corrected two boundary defects without changing
the frozen science, artifact schema, or publication policy:

- Production accepted malformed returned BEDTools window fields when the derived
  counts happened to remain correct. Every returned endpoint and window now must
  match its exact generated record and form a valid incidence. Window labels have
  an indexed unique lookup. Nine regression cases reject malformed coordinates,
  labels, IDs, columns, framing, and nonoverlapping pairs before publication.
- A qualification catalog change between publication-token construction and fresh
  binding could publish a valid artifact under a token that recovery could not
  reconstruct. Execution now checks the token against the freshly bound resource,
  qualification, and backend identities before creating output. A regression
  changes catalog serialization in that gap and verifies fail-closed behavior.

With both fixes, the complete QC suite passes **88 tests (203.86 seconds)** and
the affected resource/common-reader/orchestration/provider/benchmark/Application/
report suites pass **1,425 tests (37.58 seconds; 3 existing warnings)**. A separate
synthetic audit checked 4,003 endpoint positions with actual qualified BEDTools,
the independent verifier, and a direct point/window oracle, including overlapping
and opposite-strand TSSs. This adds no biological qualification claim.

The full lightweight command above was rerun after both fixes with no exclusions:

# M11.4c — Explicit QC selection and M11.4 closeout

M11.4 V1 provides this explicit, independently verified path:

```text
verified scatac-fragments.v2
→ scatac-barcode-qc.v1
+ explicit_qc_thresholds.v1
→ scatac-cell-selection.v1
→ ordered QC-selected candidate-cell set
```

M11.4a's science/resource APIs and M11.4b's metrics remain unchanged. Selection
is optional: metrics-only workflows remain valid. Statistical background-versus-
cell calling is **not assessed** (`cell_call_method=none`,
`cell_call_state=not_assessed`). This is not OrdMag, knee calling, EmptyDrops,
Cell Ranger calling, a cell probability, or a doublet classifier.

## Public API and exact policy

```python
from agent.tools.data.scatac_cell_selection import select_scATAC_cells

result = select_scATAC_cells(
    barcode_qc_manifest_path=qc_result["manifest_path"],
    barcode_qc_manifest_sha256=qc_result["manifest_sha256"],
    min_qc_fragment_records=100,       # illustrative explicit caller choice
    min_tss_enrichment="1/10",        # exact, not a suggested biological cutoff
    output_dir="/absolute/managed/selection",
    min_tss_flank_evidence=None,
    max_qc_fragment_records=None,
    max_nucleosome_signal=None,
)
```

The method is `explicit_qc_thresholds.v1`. Minimum QC-record depth and minimum
TSS enrichment are required; there are no hidden defaults. Optional minimum
flank evidence, maximum QC-record depth and maximum nucleosome signal are disabled
when omitted or explicitly null. All enabled minima use `>=`; maxima use `<=`.
Even an intentionally unsatisfiable combination is valid and may select nothing.

Integer thresholds are nonnegative Python/JSON integers bounded by 10^18 (booleans
are invalid). Ratios accept those integers or strict strings: an integer, a decimal
with 1–18 fractional digits, or `numerator/positive_denominator`. Integer components
have at most 19 digits; reduced numerator and denominator are bounded by 10^18.
No signs, whitespace, exponent notation, leading integer zeros, separators,
NaN/Inf or binary floats. `1`, `"1.00"` and `"2/2"` have the same effective ratio.
Effective ratios persist as reduced integer numerator/denominator pairs. Original
validated arguments are also bound; distinct spellings may have distinct execution
identities even when their decisions agree.

TSS comparisons use exact `200*C / (101*(L+R))`; nucleosome comparisons use exact
`mono/free`. Production cross-multiplies integers. The verifier separately parses
thresholds and compares `Fraction` values. Neither consumes rounded report values.
Undefined TSS fails the required minimum even when that minimum is zero. Undefined
nucleosome signal fails only when its maximum is enabled. Optional flank evidence
uses `L+R`, independently of TSS validity. No QC definitions or support semantics
can be configured through this tool.

All applicable reasons are retained in this fixed order:

1. `QC_FRAGMENT_COUNT_BELOW_MIN`
2. `TSS_ENRICHMENT_UNDEFINED`
3. `TSS_ENRICHMENT_BELOW_MIN`
4. `TSS_FLANK_EVIDENCE_BELOW_MIN`
5. `QC_FRAGMENT_COUNT_ABOVE_MAX`
6. `NUCLEOSOME_SIGNAL_UNDEFINED`
7. `NUCLEOSOME_SIGNAL_ABOVE_MAX`

Counts per reason may overlap and do not form a partition. Selection equals QC
pass under this V1 policy; no separate statistical cell call is inferred.

## Artifact, identity and sidecars

The immutable closed `agent.scatac-cell-selection` schema 1 manifest binds the
contract, `select-scatac-cells-v1` publication policy, exact arguments, QC manifest
path/hash and QC identity, source/reference/resource/science/producer qualification
lineage, complete selection profile and hash, canonical effective thresholds,
sidecar paths/sizes/hashes, observed/selected/rejected/not-assessed counts, reason
counts, readiness, ordered selected digest and domain-separated manifest identity.

`decisions.tsv.gz` contains a header and exactly one row per source QC tuple:

```text
namespace barcode_identifier rendered_cell_id cell_call_state qc_pass qc_selected failure_reasons
```

Fields are tab-separated ASCII. States are `not_assessed`, `true`/`false`, and
comma-separated ordered reasons or `NONE`. QC metrics are not redundantly copied.
Decision order is the exact QC order: namespace ASCII bytes, then barcode ASCII
bytes. Identities retain case, punctuation allowed upstream, suffixes and namespaces.

`selected.tsv.gz` has a header and exactly the selected subset, in that same tuple
order, with contiguous `matrix_row_index` from zero, namespace, barcode and rendered
ID. Empty selection succeeds with a header-only sidecar and
`readiness=no_selected_cells`; otherwise readiness is `selected_candidates_available`.
Both gzip files use empty filename, mtime zero and level 6. No timestamp or random
identifier affects authoritative sidecar bytes.

Rendered IDs use `scatac-cell.v1.<namespace>.<barcode>`, where each component is
unpadded canonical base64url of the original ASCII bytes. The strict decoder rejects
padding, invalid alphabets, invalid upstream identities, extra components and
noncanonical unused bits by roundtrip comparison. Maximum rendered length is 529
characters. Sorting always uses the original tuple, not this representation.

The selected digest is SHA-256 over `agent.ordered-selected-cells.v1\0` followed
by each selected `namespace + TAB + barcode + LF`. The empty digest is SHA-256 of
that domain alone. It never invokes an identity helper requiring a nonempty set.

## Verification, lifecycle and resource behavior

Execution first freshly verifies QC, including its existing upstream producer and
resource qualification requirements. Ordinary selection calculation streams only
the authoritative QC table. The selection verifier freshly verifies QC, separately
canonicalizes thresholds and evaluates all reasons, independently renders IDs and
reconstructs selected indices/order/digest and summaries, then compares exact
sidecar contents and hashes. It never calls production selection/decision/rendering
helpers. Shared bounded parsing, schemas and IO do not decide selection.

An altered fixed comparison profile is rejected by the closed schema. Self-consistent
sidecar hashes do not establish correct decisions: rehashed scientific forgeries
must still pass independent reconstruction. Exact public arguments and receipts
also prevent substituting another QC pointer, even if table values are identical.

Durable identity binds the existing run/plan/step/tool execution identity, exact
arguments (including QC hash), fixed selection profile, effective thresholds and
output destination. Private output is independently verified, fsynced and atomically
renamed. Recovery uses the exact receipt and fresh selection verification, without
production reruns, scanning or threshold changes. Cooperative checkpoints cover
streaming, hashing and lock waits; private work is cleaned and published verified
success survives later cancellation. Upstream QC reinspection retains its existing
cooperative latency and hostile-filesystem race limitations.

Selection adds no fragment materialization, per-barcode JSON manifest, cell-by-TSS
matrix, or population-sized Python collection. It holds one row and bounded reason
counters. Limits inherit 10 million observed tuples, 4 KiB decoded rows, 1 MiB
manifest and 16 GiB compressed sidecars. End-to-end fresh verification still incurs
M11.4b's TSS lists, upstream barcode set and disk-backed reconstruction; it is not
constant-memory end to end. Large-scale throughput remains unqualified.

## Integration and planning

Tool seventeen is `select_scATAC_cells`. Its reviewed ports consume
`barcode_qc: scatac_barcode_qc.v1` and produce
`selected_cells: scatac_cell_selection.v1`. Thresholds are explicit request inputs;
the current LLM wire does not permit executable literals. Managed output is
mechanical. Missing required parameters or invalid individual threshold shapes fail
planning/preflight without scientific IO. No compiler special case, producer routing,
automatic QC insertion, threshold inference or mandatory selection was added.

V4 remains default; explicit v3 retains its payload contract. Prompt-only repeated
catalog values/keys are losslessly represented by legends, and v4 trailing null
guidance slots are explicitly recoverable. The public catalog/compiler and wire
constraints remain intact; existing byte ceilings are unchanged.

For the existing full-catalog inspection size fixture, v3 is **22,402 prompt +
15,428 schema = 37,830 bytes** and v4 is **19,211 + 11,269 = 30,480 bytes**.
The v3 ceilings remain 22,500/15,500/38,000 and v4 combined remains 30,500.
Independent test expansion equals the complete original catalog, including choices,
defaults, constraints and threshold semantics. A separate base comparison confirms
that reversing v3's internal definition alias restores exactly the base schema for
the current seventeen-tool registry, with empty, inspection and selection requests.
No v4 wire schema change was needed.

PLAN_ONLY opens no QC data or qualification catalog, performs no fresh verification
or selection and creates no scientific artifacts. Bounded figureless evidence/report
facts contain effective thresholds, overlapping reasons, candidate counts, exact
lineage, qualification and selected identity protection, never full decision tables.
Synthetic QC provenance remains synthetic; selection cannot upgrade it.

## M11.5 handoff and deferred science

M11.5 will consume this selection artifact, the exact verified fragments v2 artifact,
and a full ordered cCRE reference. It must compare the supplied fragment manifest
path/hash against `qc_lineage.arguments.fragments_manifest_path/sha256`, verify the
QC and selection identity chain, and match the bound parent reference identity.
It must use `selected.tsv.gz` indices/order directly, without resorting or reapplying
thresholds. Empty selection requires explicit non-readiness handling for a nonempty
matrix. Fresh upstream verification may reread fragments; ordinary threshold
calculation does not.

No M11.5 projection, cCRE matrix, automatic statistical calling, doublet detection,
FRiP, peak/blacklist overlap, or raw-derived EpiZoo inference is implemented here.
No production hg38/mm10 QC bundle is provisioned. M11.4 completion is software and
synthetic acceptance of the narrower explicit-QC-selection scope, not biological
cell-calling validation. Biological validation remains deferred to M11.8.

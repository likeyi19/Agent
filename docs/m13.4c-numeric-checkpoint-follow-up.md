contributions and float32 CSR output in both its unit-overlap and support-weighted
branches. The preprocessing and NT inference notebooks pass that floating matrix
through `global_TFIDF`. The TF-IDF function preserves the input copy's dtype when

14,920, 6,293, 15,321 and 12,846, reciprocals become zero; the original failure was
reproduced with the same four identities before testing the adapter.

The explicit representation adapter is a private sparse working-copy cast. The
largest observed count over the full canonical matrix is 107. The final admitted
range is nonnegative integers through 2^24 inclusive, exactly representable in
float32. Values above that limit are rejected by the qualification boundary;
there is no claim to support every signed-int64 value. Float32 is the narrowest
source-native representation sufficient here. An initial float64 diagnostic also
passed; its records are retained separately. Float32 was then selected to match
the source's own construction dtype. Both produced identical saved native model
input IDs for these four cells; no predictions were used to choose the dtype.

The cast performs no normalization, clipping, rounding, binarization, feature
filtering or sorting. Values round-trip exactly to int64; indices, indptr, cells
and features remain exact. Only native EpiAgent functions then perform TF-IDF,
frequency weighting, ranking, tokenization, sampling and special-token/padding
construction. Native float32 reciprocal rounding is part of that original
preprocessing, distinct from exact representation of counts before preprocessing.

## Public contract

`annotate_scATAC_cell_types` is the twentieth registered scientific tool. Its
five required arguments are `matrix_manifest_path`, `matrix_manifest_sha256`,
`annotation_spec_path`, `annotation_spec_sha256`, and managed `output_dir`.
There are no optional scientific parameters or overwrite switch.

The input matrix must be an already accepted `build_scATAC_cell_by_ccre`
publication with schema-2 scientific authority, contract
`scatac-cell-by-ccre.v1`, and science profile
`canonical-fragment-record-overlap-counts.v1`. External M12 adoption, insertion
counts, arbitrary external counts/binary matrices, and ordinary peak matrices
are unsupported by this annotation contract. No new upstream qualification occurs.

The closed, at-most-65,536-byte `scatac-annotation-inputs.v1` specification has
exactly these fields:

| Field | Required meaning |
| --- | --- |
| `schema` | `scatac-annotation-inputs.v1` |
| `source_run_id`, `source_step_id` | Exact accepted matrix execution in the operator's trusted source store |
| `species`, `assembly` | Compatible `human`/`hg38` or `mouse`/`mm10` |
| `context` | Explicit biological tissue/context; never inferred |
| `groups` | `{path, sha256, provenance}` for the exact ordered `cell_id\tgroup` TSV |
| `gene_resource`, `signature_resource` | Existing M13.3 Resource descriptors |

Each Resource descriptor contains `path`, `sha256`, `source`, `revision`,
`species`, `assembly`, `context`, `gene_namespace`, `normalization`, and
`semantics`. Gene resources use `maestro-refgenes-transcripts-exons.v1` / `none`;
signatures use `candidate-gene-list.v1` / `uppercase`. Namespaces must match.
Signature context must equal the explicit annotation context. A genomic gene
resource may declare its broader genomic context. Signatures have exact
`candidate\tgene` columns and preserve duplicate entries and their weighting.

Every matrix cell must appear once in canonical order in the group TSV. Opaque
strings, including `NA`, remain literal identities. Reordering, duplicate,
missing or unknown cells fail; at least two groups are required. No clustering
is performed. Independent groups are an explicit prerequisite, not inferred
from obs columns or step names. This initial public contract consumes a completed
matrix run; it does not implicitly complete a raw-to-annotation workflow.

Operator configuration is outside planner inputs:

- `AGENT_ANNOTATION_SOURCE_STORE`: trusted existing FileRunStore directory;
- `AGENT_ANNOTATION_MAESTRO_ROOT`: qualified pinned MAESTRO source slice;
- `AGENT_ANNOTATION_RSCRIPT`: qualified Rscript;
- `AGENT_ANNOTATION_R_LIBRARY`: qualified R package library.

The source run's existing resource/runtime environment must remain compatible.
No fetching, dependency installation, database update, or validator invocation
occurs inside the tool. The specification binds scientific resources, rather
than making PBMC an engine branch or a supported-tissue restriction.

## Scientific owner and artifact

The public owner calls the accepted M13.3/M13.4b `annotate_cell_groups` component.
Its binary working copy, Enhanced RP, fixed native marker statistics and signed
signature scoring are unchanged. Unique positive usable maxima assign primary
labels; no usable evidence, nonpositive maxima, and exact positive ties retain
missing labels with their respective statuses. Sparse unique positive evidence
is still assigned. No confidence threshold or validation gate was added.

`scatac-cell-type-annotation.v1` is a closed bounded manifest. It binds arguments,
the full input specification, source matrix authority, exact matrix/axis
identities, the frozen annotation profile, sidecar hashes/sizes, and a bounded
summary. The shared publication envelope binds execution, arguments, policy
`annotate-scatac-cell-types-v1`, profile and manifest through its receipt.

The artifact retains the component's RP, gene/cell/group axes, native and filtered
marker tables, runtime record, candidate evidence, signature coverage, group and
cell assignments, plus `annotated.h5ad`. These are auditable verification evidence;
large tables remain outside the manifest and report. Reports show at most fifty
groups and an explicit omitted-group count; the full group table remains available.

The derivative preserves canonical int64 CSR data, sparse indices/pointers,
cell/feature identities and order, existing obs/var metadata and matrix provenance.
It adds categorical obs columns `annotation_group`, `primary_annotation`, and
`annotation_status`, plus compact `uns['cell_type_annotation']` lineage. Missing
labels are categorical missing values, not the string `Unknown`. Automatic
AnnData string categorization is disabled to preserve original metadata types.
Alternate matrices/embedding slots are not part of the canonical owner contract.

Matrix science remains owned by the source matrix authority. M13 authority owns
annotation, propagation and derivative preservation. The H5AD dataset port reuses
`scatac_matrix_h5ad.v1`, allowing explicit feature-space validation composition;
the separate annotation manifest port does not masquerade as a matrix authority.

## Verification, lifecycle and integration

The existing accepted-RunStore loader imports and validates the exact source
matrix authority. A caller-supplied authority JSON cannot grant trust. Source
publication/resource integrity remains fresh; historical raw files are not
reconstructed or rehashed merely to annotate or resume annotation.

M13 owner verification independently reloads the pinned scientific inputs and
replays the accepted primary backend once. It compares RP, native/filtered marker
evidence, scores, coverage, assignments, exact cell propagation and derivative
content. This is backend replay, not a claim of a separately implemented RP or
statistical algorithm. Rehashed evidence must reproduce the pinned computation.
No M11/M12 owner, EpiZoo clustering, CellMarker or EpiAgent is replayed.

The shared VerificationContext/schema-2 issuer records that proof. Application
evidence, reports and terminal resume reuse it with fresh integrity/lineage
checks. Strict standalone annotation verification and interrupted-publication
recovery replay M13 only. The new annotation recovery policy retains issued
scientific authority across recovery and completed-step revalidation; historical
raw-only recovery policies retain their behavior. Missing/incompatible source
scientific authority fails rather than triggering implicit qualification.

Publication uses the existing matrix publication envelope with owner-specific
manifest and receipt callbacks: private staging, output lease, verified/fsynced
payloads, atomic rename, and publication relocation of the scientific proof.
Cancellation checks bracket RP; active R children are terminated and reaped before
private scratch cleanup. Cancellation after publication preserves published success.

Registry metadata supplies static ports; v3/v4 planning and AgentApplication use
existing paths. PLAN_ONLY binds the supplied inputs without reading biological
resources or executing science. Missing specification bindings are rejected.
Prompt-only phrase sharing covers catalog keys and short repeated text; null
input lineage is losslessly omitted with an explicit legend;
independent decoding tests preserve the complete catalog and unchanged size caps.
No executable wire schema or compiler heuristic was introduced.

Option A was selected: CellMarker corroboration and EpiAgent supervised validation
remain qualified private optional paths. Neither is required, gates annotation,
overwrites a primary label, or rescues an unresolved group. No voting or combined
confidence system exists. Their preprocessing and evidence remain backend-owned.

## Scope limits

Automatic clustering/tissue inference, LLM biological guessing, peak projection,
unqualified value semantics, cross-species mapping, ontology harmonization,
classifier training, public validator tools, validator-driven correction and
combined confidence remain outside this milestone. Human PBMC is the biological
qualification example; mouse and other tissue contexts require their own relevant
resource/biological qualification. No fine-subtype accuracy guarantee or benchmark
accuracy is inferred from this example. The historical 899/904 EpiAgent comparison
is broad-lineage concordance among directly comparable assigned PBMC cells,
not accuracy; EpiAgent-NT has no explicit NK class.

`Macaca_fascicularis_5.0`, genome date 2013-06 and genebuild update 2020-03.

separate ab-initio and chromosome-only exports.

Names are translated only at resource preparation through exact entries of the
**already qualified M14.8 Ensembl-to-UCSC alias table**, whose bytes are bound by
the accepted assembly classification review. No prefix replacement or runtime
alias guessing occurs. Every annotation feature is checked against the mapped
FAI length before any transcript exclusion. All 1,205,758 feature rows pass;
there are no unknown names or out-of-bounds coordinates. The 54,368 transcript
IDs are unique and gene contig/strand/coding eligibility is consistent.

The existing legacy construction profile uses the gene's protein-coding status
(`gene_type` in GENCODE). Ensembl documents the corresponding `gene_biotype`;
all 45,968 eligible source transcripts also independently have
`transcript_biotype=protein_coding`. Thus there is no eligibility ambiguity or
new transcript-filtering rule for this resource. Excluding 8,400 noncoding and
608 non-primary transcripts leaves 45,360 eligible transcripts. None fails the
complete-window condition. Deduplication produces 37,316 distinct TSS sites.

`prepare_tss.py` uses the installed pysam GTF decoder. `verify_tss.py` separately
reconstructs every eligible site and lineage row from raw GTF fields and compares
the entire BED4 and lineage byte-for-byte. `annotation-audit.json`,
`normalization.json` and `qualification-evidence.json` retain the source,
completeness, bounds, eligibility and independent reconstruction evidence.
This is release-specific resource preparation outside the Agent runtime, not a
universal annotation parser or a macaque QC engine.

Frozen semantics are unchanged: transcript [a,b] becomes [a−1,b), plus TSS is
a−1 and minus TSS b−1; exact (contig,position,strand) sites collapse, opposite

Center/flank windows are [−50,51), [−2000,−1900), [1901,2001); fragment endpoints
are start and end−1; enrichment is exactly 200C/(101(L+R)).

## Frozen acceptance-only selection policy

No documented threshold set for this preserved macaque dataset was found.
Before QC execution, `selection-policy.json` fixes `min_qc_fragment_records=1`
and `min_tss_enrichment="1"`; all optional criteria are disabled. These require
observed primary-fragment evidence and defined center density at least equal
to flank density. They are deliberately permissive **acceptance-run explicit
criteria only**, not calibrated biological thresholds, macaque defaults,
arbitrary-species defaults or a cell-purity claim. No threshold tuning is allowed
after seeing the selected count. Calling remains `none/not_assessed`.

This milestone adds a data-layer adapter around public EpiZoo. The final real
acceptance uses the supplied pretrained EpiZoo and SEAM checkpoints with a complete
artificial target vocabulary. It establishes technical backend compatibility,
not biological adaptation performance, convergence or full-vocabulary capacity.

- `contract.py`: closed scientific/execution profiles, resource hashing and JSON.

resources where applicable, and an absolute output directory. There is no device,
strategy, precision, batch-size or resource fallback. `execution_profile` produces
the closed qualification/production settings; edited dictionaries fail validation.

## Target preprocessing

The initial adaptation profile accepts only M14.1 exact external
`scatac-cell-by-features.external.v1` with declared `fragment_counts`.
The public tutorial/API uses raw count-dependent TF-IDF ranking; preserving
fragment counts is the conservative first profile. Computational acceptance of
other numeric inputs does not establish equivalence. `insertion_counts` and
`binary_accessibility` fail closed here and remain valid M14.1 matrix declarations.
No claim of biological interchangeability or annotation/model readiness is added.

The exact public functions reused are:

- `epizoo.data.processing.compute_document_frequency`
- `epizoo.data.processing.compute_tfidf`, which calls public `compute_idf` and
  `compute_tfidf_matrix`
- `epizoo.data.processing.generate_cell_sentences`

One dataset uses its own cells as the complete training corpus. Multiple datasets
must share exact species, assembly, reference manifest binding, ordered vocabulary
and qualified value semantics. A small adapter vertically stacks canonical CSR
matrices in explicit dataset/row order, then invokes the same functions on that
joint sparse corpus. There is no separate public multi-dataset DF API to invoke.
DF is consequently training-corpus-wide, with N equal to all participating cells.
No TF-IDF formula is reimplemented in Agent or its tests. Historical column-total
TF-IDF is not used. Established human/mouse corpus DF remains unchanged.

The composition limit is 64 datasets and 8 GiB of estimated canonical sparse
storage. Whole matrices are never densified. Original cell IDs are retained with
their dataset index in `cells.jsonl`; internal AnnData row labels have no external
scientific meaning. Duplicate matrix inclusion fails. Empty cells/datasets and
cells with no inaccessible feature fail explicitly for this SR/CCA profile; none
are silently dropped. All-zero feature columns remain present.

Persisted resources include int64 DF, corpus size, every matrix identity, ordered
feature digest, float32 TF-IDF profile/scale 10,000, original cell identities,
int64 sentence tokens and row pointers. Independent checks call the public owner
again for deterministic preprocessing and reject rehashed scientific forgeries.

## Sequence, sentence and transfer semantics

`extract_dna_sequences` receives the exact qualified FASTA and ordered coordinates,
`fix_chrom_name=False`, `on_error='raise'`; exact lengths are checked. There is no
alias repair, clipping or skipped feature. `SEAMDataset` uses the pinned tokenizer,
512-token maximum and its public truncation behavior. An unshuffled, zero-worker
loader carries explicit feature indices into `extract_seq_embeddings`.
SEAM is eval/frozen; finite `(n_features, 512)` embeddings are stored as float32.
SEAM is released before post-training. Sequence text and embedding resources remain
bound to the exact feature order. Verification checks sequence extraction and
embedding structure/order binding, not an independent reimplementation of SEAM.

Sentences use feature index +4, no human/mouse offset. The public NumPy
`argsort(-values)` ordering is retained, with the NumPy/runtime version pinned;
no secondary tie rule is invented. `CellDatasetX` permits at most 8,190 feature
tokens plus CLS=1 and SEP=2; PAD=0. NumPy random sampling without replacement
preserves selected tokens' relative order. Rank embeddings use sequence positions.
SR targets are binary support from the full sentence before truncation. CCA
positives are the sampled/truncated accessible tokens; equal-count negatives use
inaccessible features, without replacement when possible and with replacement
otherwise (`cca_alpha=1`).

Both strategies call the existing public transfer function. Transformer/MoE,
rank embeddings, CCA head and four special rows are inherited. Target identity
rows and decoder weight/bias are initialized by the public `nn.Embedding` /
`nn.Linear` constructors; no alternative initialization is introduced. Target
sequence rows always use target DNA/SEAM. Mapped transfer overwrites only mapped
identity and decoder rows/bias from the retained source checkpoint vocabulary.
Unmapped rows keep public new initialization. An explicitly empty map is still a
mapped request, not a failed-request fallback.

Mapped input requires source species, full source reference manifest, exact target
reference identity, target-to-source chain, hashed liftOver/BEDTools binaries,
their tool banners/versions, and positive integer minimum overlap in bases.
Chain header contigs/lengths must agree with the two bound references. Source
reference rows at the pinned filter indices must match the retained checkpoint
vocabulary. Mapping calls `build_ccre_map`: original row indices survive genomic
sorting; liftOver retains its default minimum mapped-base ratio 0.95 and does not
enable `-multiple`; `bedtools intersect -wao`
selects greatest overlap. Equal-overlap ties retain first tool-output occurrence
through the public stable sort. Many targets may inherit one source row.
This mapping is exclusively for parameter inheritance, never matrix projection.

## Training and reproducibility

Architecture is fixed at 30 layers, 512 dimensions, 8 heads, four MoE experts,
top-k 2, FlashAttention, max rank 8192, normalized top-k, transformer/attention
dropout 0.1, LayerNorm epsilon 1e-12, GELU and 128-dimensional CCA head. The public
CCA head's fixed dropout and implementation are code-bound. All 790 target
parameter tensors except `seq_emb.weight` remain trainable; the sequence embedding
tensor is frozen, including its special rows.

`EpiZooXPostTrainer` owns SR+CCA training. Both objective weights are 1, SR BCE
positive weight is 100 and CCA positive weight is 1. Optimizer is public AdamW:
LR 5e-5, weight decay 0.01, betas (0.9, 0.999), epsilon 1e-8, AMSGrad false.
The public LambdaLR uses 1,000-step warmup followed by epoch decay 0.9. Model
parameters are explicitly float32; CUDA autocast is float16 with public dynamic
GradScaler. No gradient clipping is enabled.

The production schedule is the **public-default candidate**, not demonstrated
biological convergence: 500,000 steps, batch 4, save interval 4,000, log interval
500. Tutorial overrides are not promoted to validated defaults. Qualification
allows explicitly labeled batch/sequence-batch reductions, at most ten steps,
and practical save/log intervals. It never changes architecture, objectives,
warmup, trainability or sequence/transfer semantics.

Python, NumPy, PyTorch CPU/CUDA RNGs are initialized and restored; shuffle uses an
explicit torch generator; zero workers avoid uncontrolled worker seeds. NumPy
controls sentence/CCA sampling. TF32 and cuDNN benchmark are disabled for this
execution profile. The recorded environment includes Python, CPU thread counts,
PyTorch/CUDA/cuDNN, NumPy, pandas, scipy, AnnData, transformers, tokenizers,
FlashAttention, pyfaidx and Triton. Bitwise GPU reproducibility is not promised.

Public global_step counts attempted steps, including AMP skips. The artifact
separately records applied optimizer steps, skipped steps and final AMP scale.
Every loss must be finite, and at least one optimizer step must apply. The public
scheduler's behavior is preserved. No silent precision or learning-rate recovery
occurs. Training interruption is never advertised as exact resume: public
checkpoints contain model tensors, not optimizer/scheduler/RNG state.
The 500,000-step production candidate is unchanged. Whether a biological
production schedule should target attempted or applied optimizer steps remains
for full-scale training qualification; this closeout does not redefine it.

## Verification and publication

Initialization checks inheritance at the EpiZoo boundary. The completed owner
verifier reconstructs deterministic preprocessing through EpiZoo, exact DNA
extraction/order, mapping when applicable, embedding dimensions/finiteness,
execution/profile consistency, parameter scopes, frozen sequence values and
strict target reload plus bounded forward compatibility. It never trains a second
model. Structural verification does not independently reproduce learned numerical
training trajectories, prove biological quality, or authenticate undeclared history.

Within an owned context, upstream matrix and completed target proofs are reused
with fresh integrity/lineage/runtime checks. Schema-2 records distinguish historical
external sources from current model/resources. Changed checkpoints, resources or
code invalidate reuse. Parsed records alone confer no accepted execution. Source
and SEAM bundles bind both code hashes and the observed EpiZoo revision; compatible
use currently requires that exact qualified code/runtime identity. Cross-revision
compatibility admission is not automatic.

The existing lease/stage/fsync/atomic-rename machinery publishes a checkpoint,
DF/sentence/sequence resources, ordered identities, logs, manifest and receipt.
The returned result includes schema-2 authority provenance. Downstream operation
reuse and completed recovery are tested. Standalone recovery checks structural
compatibility afresh without post-training. Trusted persisted RunStore admission,
cross-run Application integration and public model-aware inference routing are
future integration work, not new data-layer trust shortcuts.

## Deferred boundaries

Real macaque/mapped acceptance needs an exact target matrix/genome/reference,
qualified real directional chain and matching full/retained source reference.
The local zebrafish example alone lacks a qualified biological target genome and
verified M14.1 provenance; it was not silently adopted or partially truncated.
Real biological new-species validation, training-corpus selection, production
schedule/convergence, full-vocabulary GPU capacity and model-quality benchmarking
remain unestablished. Other matrix value semantics require their own qualification.

Registry/Planner/Application integration, target-model inference routing, trusted
cross-run authority admission, arbitrary-species FASTQ/BAM/QC/annotation, feature
matrix construction from fragments, Evo/perturbation, distributed training and
exact mid-training resume remain out of scope. The historical TF-IDF discrepancy
is resolved for this profile by the explicit target-corpus/public-EpiZoo rule;
it does not retroactively change historical or human/mouse workflows.

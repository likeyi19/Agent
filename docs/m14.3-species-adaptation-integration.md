## Public interfaces

The registry grows from 20 to 22 tools:

- `adopt_scATAC_cell_by_features`: source H5AD path/SHA, neutral reference manifest
  path/SHA, explicit `matrix_semantics`, and managed output directory. The exact
  reference supplies its declared scientific species name, taxonomy ID and assembly.
  The accepted matrix owner proves source/output conservation. All three M14.1
  value semantics remain available for adoption; adoption alone confers no model
  readiness, curated-cCRE designation or invented raw/QC/selection history.
- `adapt_epizoo_species`: matrix manifest path/SHA, adaptation specification path/SHA,
  explicit `strategy`, and managed output directory. The first public interface
  requires the durable execution identity supplied by AgentApplication and takes
  one matrix. M14.2's internal compatible multi-matrix corpus support is
  unchanged but not exposed as an implicit input fanout.

Neutral adoption emits semantic port `matrix` with type
`scatac_cell_by_features.external.v1`; adaptation accepts only that upstream type
on `matrix`, and emits `model` of type `epizoo_target_model.v1`. There is no neutral
`dataset` port into legacy human/mouse embedding or canonical annotation. Direct
manifest input remains possible with fresh owner verification when no accepted
proof is available. This is not a parsed-authority import shortcut.

The new `species_adaptation` capability contains exactly these two tools. It is
metadata membership, not a recipe: selection and composition remain model-owned.
The legal matrix edge is derived by the unchanged semantic compiler. Missing
request bindings and wrong ports fail compilation/preflight. The existing
human/mouse capabilities, tools and scientific contracts are unchanged.

## Explicit adaptation input specification

`epizoo-adaptation-inputs.v1` is a canonical bounded JSON file with exactly:

```json
{
  "contract_version": "epizoo-adaptation-inputs.v1",
  "reference_identity_sha256": "<exact neutral reference identity>",
  "species": {"scientific_name": "Danio rerio", "taxonomy_id": 7955},
  "assembly": "<explicit assembly>",
  "source_bundle": {"path": "/absolute/source-bundle.json", "sha256": "<sha256>"},
  "seam_bundle": {"path": "/absolute/seam-bundle.json", "sha256": "<sha256>"},
  "mapping": null,
  "execution_profile": "qualification.v1"
}
```

This is a template, not a valid executable resource. Callers/operators supply
actual identities through the existing M14.1/M14.2 provisioning APIs. The LLM sees
input names/types and semantic guidance, never structured input values or resource
hashes. No directory discovery, inferred species, mapping fallback or resource
fabrication occurs.

The public `strategy` must be `de_novo` or `mapped_reference`. De-novo requires null
mapping; mapped requires the complete M14.2 mapping specification: explicit source
species/reference, target identity, directional chain, liftOver/BEDTools identities
and banners, minimum overlap and `target-to-source` direction. Mapping remains
parameter inheritance only, never matrix projection.

Execution-time prerequisite checks validate the specification hash, matrix manifest
hash, declared species/assembly/reference/fragment-count semantics and supplied
resource locators before backend execution. Current EpiZoo revision, adapter code
and runtime must equal both qualified bundles even during accepted-authority reuse.
M14.2 then performs its unchanged full
resource, vocabulary, structural and scientific verification. PLAN_ONLY performs
only existing structural/compiler validation: it never reads these files, opens
matrices, loads checkpoints, executes SEAM or creates target-model artifacts.
Unavailable resource contents cannot be diagnosed by IO-free PLAN_ONLY.

## Authority, publication and recovery

Wrappers call the existing matrix and adaptation owners, receipt policies and
atomic publication machinery. No new verifier, trainer, trust store or long-job
execution framework exists. Schema-2 authority binds exact durable execution.
The public specification is checked again when reconstructing the publication
identity; expanded arguments must match the immutable backend manifest/receipt.

Within the Application authority operation, matrix conservation is proved once,
then reused by adaptation. M14.2 performs one SEAM production and one post-training
execution; its structural verifier checks deterministic preprocessing, resources,
checkpoint and finite forward compatibility once. Evidence/reporting reuse the
accepted persisted authorities with fresh integrity/lineage/runtime checks.
Mutation or incompatible resources fail closed. Historical source policy does not
reconstruct/re-read the external H5AD after its accepted conservation proof.

The existing annotation recovery authority mechanism is extended narrowly to the
two new tools, preserving authority on recovered/revalidated steps. Neutral species
objects are serialized from persisted immutable mappings before result validation.
A crash after publication can recover the exact receipt without production. A crash
without a completed receipt cannot silently restart training. Cooperative cancellation
cleans private stages, and terminal cancellation remains cancelled on resume.

The standard report is deterministic and figureless. Whitelisted facts include
species/assembly, reference/vocabulary and training matrix identities, source-model
and SEAM bundle identities, strategy/mapping identity, profile, trainer attempts,
applied/skipped optimizer steps, target checkpoint and manifest identities. Reports
do not establish convergence, biological performance, cross-species accuracy or
embedding quality. Schema-2 lineage remains attached to the accepted run steps.

## Public capability and request resources

Registry grows from 22 to **23**. The new tool consumes three explicit manifest
path/SHA-256 pairs and a managed output directory:

| Semantic input | Public arguments | Required resource |
| --- | --- | --- |
| `fragments` | `fragments_manifest_path`, `fragments_manifest_sha256` | Verified externally adopted `scatac-fragments.v2` with neutral reference binding |
| `explicit_cells` | `explicit_cells_manifest_path`, `explicit_cells_manifest_sha256` | `scatac-explicit-cells.v1`, exact caller order |
| `reference` | `reference_manifest_path`, `reference_manifest_sha256` | `regulatory-feature-reference.v1` |
| `output_dir` | `output_dir` | Existing managed publication mechanism |

There are no public counting, BEDTools, SQLite or serialization knobs. Operator
configuration remains `AGENT_MATRIX_BEDTOOLS`. The public adapter calls the
unchanged `fragment_feature_matrix.build_cell_by_features` owner and retains
`build-scatac-cell-by-features-v1` publication/recovery identity.

Inputs use existing grouped request-resource bindings. Callers provision neutral
external fragments and explicit cells through the accepted M14.6 data APIs before
submitting their pointers. `explicit_cells.publish_explicit_cells` remains an
operator/caller resource API, not an LLM scientific tool. No implicit conversion
of barcode lists or automatic artifact publication occurs during planning.
There is no new arbitrary-species raw-import tool in this milestone.

All three scientific input ports are request-only: the currently registered
fragment producers are legacy human/mouse producers, and no registered tool emits
neutral explicit cells or a neutral reference. Allowing those producer ports here
would falsely admit incompatible upstream science. In particular, QC-selected
cells cannot replace explicit cells. A future registered neutral producer can add
its exact reviewed port without a workflow recipe.

The output `matrix` port has semantic type `scatac_cell_by_features.v1` and carries
`manifest_path`/`manifest_sha256`. It emits no legacy canonical-H5AD `dataset` port.
`adopt_scATAC_cell_by_features` retains its distinct
`scatac_cell_by_features.external.v1` output and exact external conservation
scope. Compatible sparse representation never equates those authorities.

## Planner, compiler and preflight

The existing `species_adaptation` capability now includes build, adopt and adapt.
Its description explicitly includes matrix-only fragment/barcode/feature requests.
This is membership and guidance only, with no tool ordering, preferred producer,
workflow completion, keyword routing or new planner algorithm. Existing capability
IDs, v3/v4 schemas, compiler lowering and private-input exclusion remain intact.

Scripted scoped planning covers matrix-only and build→adapt requests. Existing
H5AD requests still use adopt→adapt; human/mouse routes keep their prior ports and
science. Missing explicit cells cannot generate calling or selection steps.
Wrong ports, missing pairs and mechanical knobs fail closed. The compiler derives
unique source ports; models need not serialize redundant `matrix` port names.

Structural preflight checks explicit required bindings, absolute paths, hashes and
legal producers. PLAN_ONLY performs no scientific IO: species/assembly/genome and
barcode compatibility stored inside manifests cannot be determined in this mode.
Execution-time owner prerequisite checks verify exact manifest identities, neutral
species/assembly, full FASTA/FAI/contig compatibility and namespaces before counting.
Absent barcodes are rejected by the accepted streaming matrix engine; present
zero-overlap rows remain. Duplicate declarations fail at explicit-cell provisioning.
No inference, sorting, dropping, contig repair or liftOver is added.

## Adaptation compatibility

Adaptation's `matrix` port accepts both reviewed neutral matrix semantic types.
A small closed lineage accessor reads the external reference binding or the
fragment-derived `upstream.reference`, and reads each contract's declared/fixed
semantics. It validates each original contract without rewriting either artifact.
The existing independent matrix verifier remains authoritative. Fragment-derived
verification uses the explicit operator BEDTools runtime, including proof reuse.

Sparse corpus loading, exact rows/columns, TF-IDF, SEAM, training and all profiles
are unchanged. Tests exercise the real sparse corpus binding and public adaptation
specification expansion without loading models or running training. Fragment
matrix identities and upstream fragment/cell lineage remain intact. Wrong
species, assembly, reference and binary-profile substitution fail.

The unchanged SR/CCA eligibility rule still requires every training cell to have
positive and inaccessible features. Thus the accepted three-row matrix is a valid
build result but its zero row Z is not an eligible adaptation corpus. A separate
explicit B/A declaration tests successful corpus admission; no cell is silently
dropped. Legal DAG composition does not establish model readiness.

Agent's adaptation adapter source changes are included in the existing resource
code-bundle identity. Previously pinned adaptation bundles must match the current
adapter through normal qualification; no old hashes are rewritten or compatibility
checks bypassed. EpiZoo source/checkpoints and training science are untouched.
No new real-model training was needed or performed.

## Application, ownership and reporting

Existing persisted execution, composition locks, scientific leases, cancellation,
atomic publication, receipts and schema-2 issuance are reused. Registration extends
the same public authority/recovery dispatch used by M14.3. No application runner,
trust store, matrix serializer, overlap implementation or scientific verifier is
introduced. Shared M14.6 matrix production and interval-tree reconstruction are
unchanged.

Fragment authority owns external-source conservation, explicit-cell authority owns
only declared identities/order, and the matrix owner reconstructs exact counts.
Accepted operation-local and persisted authorities prevent repeated reconstruction
in evidence/reporting and terminal resume. Current source/index integrity remains
required by M14.6; changes to source, matrix, cells, reference or receipt reject
reuse. Exact interrupted-publication recovery does not rerun production and issues
accepted matrix authority. Cooperative cancellation publishes nothing and does
not silently restart on resume.

Deterministic figureless reporting includes species/assembly, complete dimensions,
logical identity, counting profile, upstream fragment/cell/reference identities,
feature category and declared provenance, external producer scope, and exact
execution/publication identities. Original `peak_set`/unknown provenance is
reported truthfully. No QC, statistical calling, biological cell validity, curated
cCRE designation or downstream model readiness follows from this result.

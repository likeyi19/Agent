# M14.9 — Arbitrary-species BAM to verified fragments

M14.9 adds a data-layer neutral reference binding to the accepted paired-ATAC BAM
producer. Output remains `scatac-fragments.v2`. There is no second BAM parser,
pairing algorithm, coordinate transformation, matrix engine or registered tool.
This is bounded synthetic technical qualification; real-BAM biological acceptance
and public neutral-BAM production wiring remain follow-up work.

## Input and producer contracts

Entry point:

```python
from agent.tools.data.neutral_bam import prepare_neutral_bam_fragments

result = prepare_neutral_bam_fragments(
    input_spec_path="/absolute/inputs.json",
    input_spec_sha256="<sha256>",
    output_dir="/absolute/output",
    execution_identity="<optional durable identity>",
)
```

The bounded canonical JSON `neutral-bam-inputs.v1` has exactly these fields:

- `contract_version`: `neutral-bam-inputs.v1`.
- `source`: exact BAM `{path, sha256, size_bytes}`.
- `source_index`: null or an explicitly supplied index resource with the same
  three fields. An adjacent index is not implicitly selected.
- `source_species`: existing neutral `{scientific_name, taxonomy_id}` contract.
- `source_assembly`: exact case-sensitive assembly identifier.
- `source_reference`: exact neutral reference-manifest resource. This is the
  explicit declaration of the reference used for alignment, not an inference
  from chromosome names.
- `primary_scope`: exact `primary-nuclear-contigs.v1` resource.
- `library`: `namespace`, nullable `source_library_id`, `barcode_tag="CB"`,
  `barcode_interpretation="corrected_identifier"`,
  `correction_policy="already_corrected"`, `assay="paired_atac"`.
- `source_history`: `coordinates="declared_unshifted"`,
  `duplicate_pairs="declared_retained"`,
  `upstream_history="not_independently_established"`.

Use the existing canonical JSON serialization and hash the exact bytes. References,
FASTA/FAI, ordered contig dictionary, complete classification, classification
source and feature vocabulary are verified with their existing owners. Source
species and assembly must exactly match the reference. This initial producer
uses the existing regulatory-feature reference machinery; it does not introduce
a genome-only reference contract.

## BAM science and primary scope

Production reuses `bam_fragments.generate`, `alignment`, `pair` and `aggregate`.
The independent owner reuses `bam_fragments_verifier.reconstruct`, `_read` and
`_template`; it does not call production's eligibility or transformation helpers.
`_bam_fragment_io.project` reuses M10 structural header validation through a
private exact-neutral-reference hook; the default M10 path is unchanged. It uses
the same pinned pysam/htslib decoder, bounded
projections and external QNAME sorting. File-object opening prevents accidental
use of adjacent undisclosed BAM indexes.

Exactly one paired primary R1/R2 per QNAME is required, with matching RG (or both
absent), reciprocal mate metadata, consistent CB and valid CIGAR/reference state.
Both mates must be mapped to the same contig, proper, QC-passing, inward-facing,
and MAPQ >=30 excluding 255. Secondary records add no support. Supplementary or
primary SA evidence excludes the template. Malformed pairs/tags/CIGAR/coordinates
fail before exclusion, including on excluded non-primary contigs.

The shift remains forward reference start +4 and reverse CIGAR reference end -5,
exactly once, zero-based half-open. TLEN only checks consistency. Legal 3-prime
clips and internal insertions/deletions retain the accepted behavior; unsupported
5-prime geometry and N/P do not become eligible.

After the unchanged pair eligibility checks, neutral production and independent
reconstruction separately exclude well-formed eligible pairs outside the shared
primary scope. `non_primary` follows the existing ordered exclusion reasons.
This includes explicitly classified mitochondrial and other non-primary contigs;
there are no species-name or chromosome-name rules. No output cell selection or
barcode filtering is inferred. All-excluded input retains the existing empty
fragment-artifact failure.

Every header SQ must match a target FAI name and length; a subset or different
header order remains permitted. Even excluded BAM contigs must have exact target
FAI membership and coordinate bounds. The scope's source-only extra exclusions
do not license unknown BAM reference lengths. Optional AS and SP declarations
must exactly equal the declared assembly and scientific name. Present M5 values
are checked against FASTA. There is no alias repair, case normalization, liftOver,
assembly guessing or coordinate repair. Exact resource declarations and optional
header checks do not independently prove historical alignment correctness.

Only identical `(namespace, barcode, contig, shifted_start, shifted_end)` keys
aggregate. Every passing primary pair contributes one support unit, including
marked duplicates. CB case/suffix and namespace are preserved; output uses FAI
contig order, coordinates and ASCII barcode ordering. Support remains read-pair
support, not molecule counts. Strand is absent.

## Verification, authority and recovery

The existing stage/fsync/atomic-rename publication, immutable receipt, conflict
handling and cancellation machinery is reused. Recovery policy remains
`prepare-scatac-fragments-bam-v1`; its token already binds the selected producer
profile hash, exact arguments and execution identity. Profiles cannot substitute
for one another.

The neutral wrapper opens an existing `VerificationContext` when needed. One
independent BAM reconstruction creates the operation-local producer proof;
publication, subsequent verification and same-context downstream matrix execution
reuse it. `scientific_authority.issue` supports the data-layer owner name
`prepare_neutral_bam_fragments`, yielding existing schema-2 authority with neutral
profile qualification. This name is not a ToolRegistry entry.

Neutral authority requires current integrity of the BAM, any supplied index,
input declaration, reference resources, scope/classification source and output
closure. Mutation invalidates reuse. Legacy historical-source authority policy
is unchanged. Public matrix RunStore authority retains the BAM dependency and
current input closure; fresh Application resume reuses accepted authority without
BAM or matrix reconstruction.

Without trusted accepted authority or an operation-local proof, standalone
verification/recovery remains deep. A producer manifest or receipt alone is not
permission to skip scientific qualification. First independent admission of a
pre-provisioned BAM fragment artifact invokes its BAM owner; the matrix engine
never implements BAM science. Neutral BAM public RunStore production admission
is deferred with the public producer wiring.

An optional supplied index is verified by comparing each reference's complete
indexed record stream against a sequential decode, with bounded per-reference
hashes. Corrupt/unrelated indexes fail, and later byte mutation invalidates reuse.
No index is built or repaired. This check does not claim indexing of unmapped
records without a reference, which are not fragment contributors.

## F–H. Root cause, classification and minimal fix

Classification: **Agent request-construction/provider-compatibility defect in
the M16.2 decision schema**, not a generic Groq transport defect. The schema was
a valid general JSON Schema union, but incompatible with Groq's discriminator
requirements.

`turn_decisions.py` now emits `answer_scientific` and `execute_plan` for the two
M16.2 wire branches. Parsing checks their expected scientific intent / plan
operation and normalizes them to the existing `Answer` / `Execute` decisions.
Legacy/scripted decision forms remain accepted. Instructions name the new wire
tags. Both overlapping kinds are resolved, not just the first reported pair.

This introduces no scientific intent, authority, stored schema, session engine,
provider abstraction or algorithm. Closed-object validation, exact result/subject
admission, grounding, execution separation and all fail-closed checks remain.
Strict structured output stays enabled. No M16.1 evidence-reader change.
